- Console model: version 2; bounded labels, identity, categories/scenarios/agents and ordered composer actions. Reject malformed data without inventing entries.
- Presentation: version 2; finite validated dimensions/insets and modes from rote_config; no local policy breakpoints.
- Device snapshot: logical viewport, pixel ratio, screen geometry, pointer/keyboard/touch/audio union. Refresh on resize/display/input change; retain transport capabilities.
- Result: existing component IDs/widgets; preview/collapsed/fullscreen share owner/chat/render-revision state; exit restores focus.
- Selection: agent revision/skills/notes from authenticated correlated confirmation; send nonempty selection on ordinary dispatch; clear on owner/chat reset.
- No database entity. Clear ephemeral owner-bound content on account removal.
