# Verification quickstart

1. Run composition preflight; build current source/start Docker. Confirm health/readiness and runtime identities before captures.
2. User completes normal Keycloak sign-in. Capture/index web states at spec dimensions; publish vault checkpoint before native UI edits.
3. Run focused Projection ROTE/chrome/renderer and Deep landing/chrome/selection tests with Python3.11/exact components. Run real-shell browser regressions for shared changes.
4. Apple: `swift test --package-path components/AstralProjection/apple-clients/AstralCore --enable-code-coverage`; recursive strict swift-format with committed config; unsigned AstralApp iOS Simulator/macOS builds; affected XCTest/UI suites and shared-core watch checks. Use committed project/schemes.
5. Live iPhone/iPad/macOS against Docker: sign-in, reference walkthrough, resize/keyboard/fullscreen/history/selection/mandatory settings. Save comparison evidence and checkpoint vault.
6. Then Android: committed wrapper `ktlintCheck :app:lintDebug :core:test :app:testDebugUnitTest :core:koverVerify :app:koverXmlReport :core:koverXmlReport :app:assembleDebug --no-daemon --stacktrace`, plus workflow instrumentation/protocol checks. Verify phone/tablet live and checkpoint.
7. Run affected workflow-equivalent checks, changed coverage, composition/protocol validation and diff review. Record exact commands/counts/failures/toolchains in `verification.md`. Hosted CI requires an authorized product push; release/deployment are separate.

Do not bypass sign-in, substitute fixture-only acceptance, skip failing gates or weaken assertions. Preserve unrelated changes; logs that may contain operational data stay outside vault.
