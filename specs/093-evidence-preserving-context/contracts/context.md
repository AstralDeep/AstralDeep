# Context contracts

Independent default-off `FF_OBSERVATION_PACKING` / `FF_SAFE_COMPACTION`. Both-off is baseline; enabled mechanisms suppress affected legacy loss. Compaction-only creates no archive, packing-only creates no automatic summary. Disable stops new mechanism work; retained references still enforce current grant and absolute expiry.

Host retention grants bind owner/conversation/audience/source agent/tool/deadline exactly. Model/user tool arguments cannot mint grants. Missing/ambiguous/expired/changed policy refuses capture. Maximum 24-hour expiry never slides; restart is unavailable. Limits: 16 KiB pages, 8 MiB observations, 64 MiB/conversation, stricter supported privacy/global bounds.

`evidence-1.recall_observation(reference, offset=0)` uses tools:read; `delete_observation(reference)` uses tools:write; `context_usage()` and `inspect_context_view(view_id)` use tools:read. Authority comes from trusted server dispatch context and fresh current original-source gates. Ordinary permission/delegation/confirmation/audit/governed path remains mandatory. Foreign/unauthorized/unknown refs receive uniform blocked response without extent/existence/content. Authorized unavailable/corrupt source gives honest recovery state only while current original-source authority and unchanged metadata policy remain provable. Revoked references and unavailable references whose source/delegation proof was cleaned up receive the uniform denial. Refusal audit failures cannot release existence metadata. Recall never reexecutes source.

The evidence adapter is host-only and never enters standalone process discovery. New packing requires its current host-bound recall adapter and in-process placement before capture and after awaited admission work; unavailable placement preserves the complete result. Enabled `/evidence` inspection commands are parsed before generic skill aliases or slash expansion and retain ordinary audited dispatch and fresh delivery verification. Both-off behavior and the global skill-alias registry remain unchanged.

Pages are exact permitted UTF-8, deterministic bounded byte slices with identity/digest/range/total/continuation/end. Preview/outcome/omission/recall instructions are code-owned. All evidence remains untrusted. Canonical assistant commits contain only strictly reconstructed bounded labels, opaque references, digests, byte ranges and known/unknown usage; source/preview/generated text never enters those commits or durable workspace/completion summaries.

`chrome_open(surface="evidence", params=...)` requests source/preview `{kind, reference, offset?}`, generated summary `{view_id}`, or usage `{kind:"usage"}` through a fresh authenticated read-only metadata operation. Owner, active conversation, current connection and canonical UUID4 request generation come from ingress authority, never tool/model arguments. The ordinary evidence tool executes under the unchanged ContextAuthority API, current source proof and original IAM/delegation gates. After every awaited read/verification, the host rechecks the live operation, navigation, adapter, privacy, source integrity/permissions/grants and exact response immediately before sending one transient modal.

Projection's versioned `evidence_inspection` presentation contract uses existing `chrome_render`/`chrome_surface`, `chrome_open` and literal KeyValue primitives. Web, Windows, Android, macOS and iOS require exact current correlated replies; navigation, close, send, timeout, account/registration/connection changes retire the request and clear evidence text. No evidence request enters an offline replay queue. Watch receives content-free metadata and an explicit phone/desktop handoff; the host omits unsupported inspection buttons and source text.

Generated views have opaque `view_` references, exact owner/conversation/audience, integral immutable text and original source dependencies. They retain at most 16 KiB per view, 1 MiB/64 views per conversation and 16 MiB/256 views globally without evicting live records. Absolute expiry is the earliest of ten minutes or any original-source deadline and never extends; restart, source revocation/deletion/expiry, privacy refusal, integrity mismatch or lost adapter/source authority makes the view unavailable. Inspection rechecks every original source through ordinary read gates. Unavailable capture commits honest metadata only; it never reports that generated text was saved.

Compaction binds the exact owner provider/content route, complete eligible input and immutable protected snapshot. Summaries are assistant evidence. System/developer/current user/tool groups/actual outcomes stay verbatim. Errors/empty/malformed/cancelled/stale/oversized/invalid-source/ineffective results preserve history; irreducible context pauses explicitly before another dispatch. All attempts/rejections/calls are bounded and audited.

Physical-attempt UUIDs and revisions deduplicate bounded usage metadata through existing Plane-backed audit. Direct/auxiliary/retry/cache/charged failure/cancellation/late/recall traffic count once. Missing usage/pricing is explicitly unknown; no verified savings from unknown totals. No raw evidence/credentials/endpoint/error bodies in metadata.

Every usage disclosure refreshes bounded public audit provenance. Same-conversation or unscoped-owner ordinary receipts without a trustworthy physical-attempt link leave recovery incomplete while preserving known tracked totals; they cannot justify complete zero-cost accounting. Actual SDK messages remain full serialized request members and reference guards apply to message content, independently of tool-schema declarations. Cached references retain current provider/source/privacy gates after flag disable; disabled compaction cannot dispatch another auxiliary proposal.
