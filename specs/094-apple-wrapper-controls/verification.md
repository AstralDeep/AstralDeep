## Confirmed fixes and review seams

- Native ROTE preserves untyped form action metadata instead of degrading it into empty text. Actions, form submissions and implicit custom-color saves share the host interaction budget; read-only/exhausted controls expose an honest unavailable state. Accepted theme frames carry display state without consuming a write allowance.
- Web/native choice normalization separates readable labels from submitted values and retains saved defaults absent from a catalog. Provider labels are supplied by the server.
- Native form actions retain distinct named operations, current form/socket ownership and duplicate-pending protection. Canonical authenticated native ingress records one current registry-owned request per socket, including queued same-form navigation. Ordinary results and constrained blank closes echo that generation; authority is checked again after awaited delivery validation. Retired Save completion cannot dismiss a newer Theme or provider draft. Private Guidance/Work generation and selection rules remain mandatory.
- Native Drafts uses owner-scoped Plane retrieval and existing approval/refinement/revision handlers. Advanced selection ingress forwards the navigation/token context already captured at the authenticated boundary.
- Accepted appearance replaces account palette state; rejected/canceled custom colors do not optimistically repaint the app. Arbitrary validated color editing replaces the former limited choice menu.
- Adaptation errors produce explicit unavailable notices; unadapted raw controls are no longer delivered after an adaptation exception.
- Provider Save validates and atomically commits encrypted settings with the completed operation, then acknowledges and unlocks required setup. Audit/probe work is separate and bounded; external rejection, exception or timeout reports a sanitized warning without clearing storage or reclassifying completed Save. All five native/web device paths, legacy callers, slow audits, failed delivery, failed persistence, consent and changed-endpoint denials are covered.
